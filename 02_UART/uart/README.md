# UART 串口通信考核

使用 Python 3 标准库，无需安装 pyserial。运行环境为 Linux，串口配置 115200、8 数据位、无校验、1 停止位（8N1）。

## 运行

在资料根目录打开终端一：

```bash
./02_UART/virtual_serial_tester
```

在测试器等待连接的 5 秒内，在终端二从资料根目录运行：

```bash
cd 02_UART/uart
python3 uart_echo.py --count 4
```

默认连接 /tmp/test_com。官方附件总共发送四组测试，指定 --count 4 后正常退出。持续监听其他设备可使用 --port /dev/ttyUSB0；默认连续 10 秒未收到有效包时报错，可通过 --timeout 修改。测试器退出后持续监听程序会报告连接断开。

## 协议

| 偏移 | 内容 |
| --- | --- |
| 0 | 固定 FF 包头 |
| 1 | uint8 |
| 2–3 | int16，大端 |
| 4–5 | int16，小端 |
| 6–14 | 9 个零填充字节 |
| 15 | 固定 0D 包尾 |

解析后输出三个十进制数值，使用解析值重新编码回传。流式缓冲处理分包与粘包；校验包尾、填充，遇到坏包逐字节寻找下一包头。数据中的 FF 不会被直接当作分隔符。非阻塞写入会处理短写。

## 验证

```bash
cd 02_UART/uart
python3 test_protocol.py -v
```

四项自动化测试全部通过：有符号边界、全部 15 个拆分位置、噪声/错误填充/粘包、错误包尾重新同步。官方附件四组测试（正数、负数、零、边界）全部回传一致，详见 verification.log。
